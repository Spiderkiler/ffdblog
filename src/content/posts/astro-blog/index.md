一直想有一个完全属于自己的角落。不是社交平台上的主页，也不是简历旁边的一行链接，而是一个可以慢慢生长的地方。于是有了这个博客。

## 为什么是 Astro

原因很简单：我想要的是内容，不是一套需要一直养着的服务器。

Astro 默认输出纯静态 HTML，没有数据库，也没有常驻进程。浏览器拿到的就是提前生成好的页面，快、稳，而且几乎不需要维护。写完一篇 Markdown，提交，剩下的交给构建流程。

当然，前面是ai生成的，真正的原因是一个非常源远流长的故事，在这里不赘述，结论就是我参考了苏晓晴的个人博客<https://blog.toubiec.cn/> 这是一个大美女程序员的技术博客。大家一定要去欣赏一下。

这套博客用到的东西并不多：

| 能力    | 方案               |
| ----- | ---------------- |
| 页面与路由 | Astro 5          |
| 样式    | Tailwind CSS     |
| 全文搜索  | Pagefind         |
| 评论    | Giscus           |
| 部署    | Cloudflare Pages |

## 一套简单的内容模型

每篇文章就是一个 Markdown 文件，开头写清楚元信息，正文随便写。没有后台，没有「保存草稿」按钮，只有编辑器和 `git push`。

```yaml
---
title: 文章标题
published: 2026-10-20
description: 一句话摘要
image: ./cover.webp
tags: [Astro, 前端]
category: 技术
draft: false
---
```

分类只保留「技术」和「生活」两个。它们不是严格的知识体系，更像两种心情：一种想把事情弄明白，一种想把日子过慢一点。

## 中文阅读体验

中文排版值得多花一点心思：

- 正文行高保持宽松，长段落不挤在一起
- 中文字体优先使用系统字体，避免加载几 MB 的字体文件
- 代码块与正文使用不同的字体，阅读时更容易区分
- 暗色模式不是把白色反过来，而是重新调过的一套颜色

:::note
如果你也在搭自己的博客，建议先想清楚「写给谁看」。这个问题的答案会决定很多看起来微不足道的选择：字号、留白、文章长度，甚至要不要评论区。
:::
